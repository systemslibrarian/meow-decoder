📚 How Cat Mode Works

  • Encryption: Server-side Argon2id + AES-256-GCM (production security)
  • Binary Encoding: Encrypted data converted to binary (0s and 1s)
  • Visual Transmission: Each bit displayed via eye color - green = 1, dark = 0
  • Video Recording: Automatically records transmission, downloadable for phone transfer
  • Decoding: Extract binary from saved video, decrypt with password
✅ Production-Ready Encryption:
  • Argon2id key derivation: 512 MiB memory, 20 iterations, 4 threads
  • AES-256-GCM authenticated encryption with 96-bit nonces
  • Automatic video recording for air-gap transfer
