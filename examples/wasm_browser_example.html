🔮 Generate Post-Quantum Key Pair

Hybrid X25519 + ML-KEM-1024 encryption. Secure against both classical computers AND future quantum computers. This is NIST's newly standardized post-quantum algorithm!

🛡️ Why Post-Quantum?

Standard encryption (RSA, ECDH) will be broken by quantum computers. ML-KEM-1024 uses lattice-based math that remains secure. We combine it with X25519 for hybrid security — safe even if one algorithm fails.

⚠️ Post-Quantum Not Available

This build of Meow Decoder was compiled without ML-KEM support. Rebuild with --features wasm-pq to enable.

🚨 Duress Mode (Panic Password)

Warning: This sets up a panic password. If entered, it will permanently destroy all stored keys and show fake decoy data. Use this if you're being coerced to reveal your password.

⚠️ How Duress Mode Works:

  • Set a "panic password" different from your real password
  • If forced to decrypt, enter the panic password instead
  • All stored keys are immediately wiped from localStorage
  • A fake decoy message is shown to the attacker
  • Your real data remains inaccessible (they'd need the real password)
